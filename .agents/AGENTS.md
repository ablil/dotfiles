# Guidlines

* use yarn, never npm
* use gradle wrapper, never gradle directly
* use gradle, never maven
* when reporting information to me, be extremly concise and sacrifice grammer for the sake of concision
* when you create PRs do NOT put me as an author, put me as a reviewer
* for java application, use Jib instead of a Dockerfile
* always use yaml for spring application properties
* avoid adding comment if the code is self-explanatory
